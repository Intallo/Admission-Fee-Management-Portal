# Glossary

| Term | Definition |
|---|---|
| Academic year | Explicit context for records, payments and certificates; has label and date range. |
| Admission Fee | Variable fee head; any amount accepted; never required for admission. |
| ADM / Admission Officer | Staff role handling admissions/records and first-step TC review; can view sensitive fields per SRS. |
| ACC / Accounts Officer | Staff role maintaining fee inputs and recording payments; cannot view sensitive data. |
| Adjustment | One-head concession, reduction, extra charge or exception with reason/approval. |
| Append-only ledger | Financial history preserved; correction uses linked reversal/adjustment, not edit/delete. |
| BRD | Business Requirements Document. |
| Final fees receipt | Once-per-student-fee receipt only after full payment; lists component receipt numbers. |
| Receipt type / fee category | Receipt book such as Fees, Books or Vehicle; more need Client confirmation/config. |
| Fee head | A billed item under a receipt type. |
| LC/TC | Leaving Certificate / Transfer Certificate; annual student/year certificate. |
| Manager signature | Receipt signatory role representing Principal. |
| Payment line | Amount against one fee head; lines sum to payment total and match receipt type. |
| Principal | Final business authority for admissions, fees and TCs per signed baseline. |
| Reversal | Linked new entry correcting/cancelling an earlier payment without erasing history. |
| SRS | Software Requirements Specification. |
| SYSADMIN | Technical System Administrator; definition is a working assumption requiring confirmation. |
| Synthetic data | Fabricated demo/test records, never real student/parent/payment data. |
| STS number | Student Tracking System number. |
| DISE number | Previous school's identification number. |
| Student status | Lifecycle status; certificate issuance does not itself set Left/Transferred. |
